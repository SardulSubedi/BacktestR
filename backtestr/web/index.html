      Replay and paper execution

      The default executable replays CSV data locally. The optional Alpaca adapter requires libcurl, a JSON library, and paper credentials. Read the generated README for execution differences and operational prerequisites. This export does not place live-money orders.

      No AI call occurs in the C++ trading loop. Daily-bar strategies do not establish high-frequency performance.

      Make the idea precise

      The interpreter turns your description into a constrained strategy specification. It asks about material gaps, lists assumptions, and rejects unsupported rules. Review the specification before running it. With an OpenAI API key, interpretation uses AI; without one, a conservative local parser handles the supported examples.

      Supported in this version

      • SMA trend: hold each symbol while its fast simple moving average is above its slow moving average.
      • RSI mean reversion: enter at or below the entry threshold; exit at or above the exit threshold. RSI uses rolling mean gains and losses, rather than Wilder smoothing.
      • Momentum: hold each symbol when its trailing price return exceeds the threshold.
      • Buy & hold: allocate to all selected symbols on the first eligible execution day.

      Active symbols receive equal weights, subject to the position cap. Unallocated capital stays in cash. Positions use whole shares, with no shorting or leverage. Extra conditions, stop losses, arbitrary weights, options, and intraday triggers are outside the first version’s rule language.

      Keep time honest

      The engine sees only completed daily bars. A signal at day t’s close can first trade at day t+1’s open. The first selected date is the initial-cash baseline; indicator warmup uses earlier history. Positions remain open at the final close. Slippage and commission are charged on each fill.

      Challenge the result

      The report includes a chronological development/holdout split, annual and rolling periods, higher transaction-cost scenarios, and a seeded block-bootstrap estimate. These are diagnostics of one fixed strategy. Repeatedly changing the rules after viewing results weakens the holdout.

      Historical prices, corporate actions, delisted stocks, point-in-time membership, trading halts, liquidity, taxes, spreads, and execution details all affect results. A selected current-stock universe can have survivorship bias. Returns are research estimates, not proof of an edge.

      Inspect the export

      C++ export uses deterministic templates and the reviewed specification. The default project builds a CSV replay executable. Its optional paper adapter has a separate dependency and credential setup, with additional order and risk checks. Paper limit-on-open orders differ from the simulation’s next-open fills. Read the bundle’s operational notes before deploying it.
